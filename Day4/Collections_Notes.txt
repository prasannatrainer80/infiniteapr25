1) List : Used to store list of values.

3) SortedSet : This interface allows you to sort the elements, TreeSet is falling under SortedSet interface.

Properties : 

Properties provides an opportunity to protect a field in class. If you want to control the internal behaviour of particular field, then we need the help of properties.  Properties are also methods will be used for value type  operations. 

There are various types of properties as 

1) Read-Only  : no Setters

2) Write-Only : No Getters

3) Read/Write  : Both Getters/Setters
